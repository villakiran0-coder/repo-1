# Daylight Calendar

A clean, responsive calendar website for planning your days. Browse months, select a date, and add or delete events with an optional time and color.

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are required. Events are stored locally in your browser with `localStorage`; they are not synced between devices.

## Publish with GitHub Pages

This repository is public. To publish the site, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. GitHub Pages will provide the public website URL after deployment.
